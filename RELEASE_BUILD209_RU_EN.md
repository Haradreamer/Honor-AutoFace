# AutoFace 2.0.6 — Build 209 / Сборка 209

## 🇷🇺 Русский

**Обновление AutoFace 2.0.6 (Android versionCode 209).**

- Автоматическое подтверждение на HONOR поддерживает **русский и английский языки системы**. Остальные языки системной кнопки пока не подтверждены.
- Добавлена проверенная на MagicOS английская фраза `Face recognition successful` и соответствующая кнопка `Confirm`.
- На главном экране отображается предупреждение о поддерживаемых языках системы с переводами на восемь языков интерфейса.
- Сохранены дизайн Isle, вибрация после подтверждения, настройка задержки и другие возможности версии 2.0.6.

**Технические данные:** `versionName 2.0.6`, `versionCode 209`. APK подписана тем же сертификатом, что и официальный релиз 2.0.6; предполагается обновление поверх предыдущей официальной сборки.

**Подписанная APK build 209:** SHA-256 `9c3a18f3bccd682a255a8660a72869dcdf6b7fca5b2c780b420e80007b3edfad`, 58 159 байт.

**Примечание:** пока файл build 209 не прикреплён к GitHub Releases, ссылка на релиз v2.0.6 ведёт на предыдущую сборку.

## 🇬🇧 English

**AutoFace 2.0.6 update (Android versionCode 209).**

- HONOR automatic confirmation supports **Russian and English phone system languages only**. Other system languages have not been verified.
- Added the observed MagicOS English success message `Face recognition successful` together with the `Confirm` action.
- Added a home-screen notice about supported phone languages, translated into all eight AutoFace UI languages.
- Retained the Isle-style UI, confirmation haptics, delay slider, and other 2.0.6 features.

**Build details:** `versionName 2.0.6`, `versionCode 209`. The signed APK uses the same release certificate as official 2.0.6 and is intended for in-place updates.

**Signed build 209 APK:** SHA-256 `9c3a18f3bccd682a255a8660a72869dcdf6b7fca5b2c780b420e80007b3edfad`, 58,159 bytes.

**Note:** Until the build 209 file is added to GitHub Releases, the v2.0.6 release download still serves the previous build.
