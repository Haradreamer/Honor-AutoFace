# AutoFace для HONOR

**Автоматическое подтверждение после распознавания лица на смартфонах HONOR.**

**AutoFace 2.0.2** — бесплатная утилита Haradreamer. Если после успешного распознавания лица системное окно HONOR требует нажать «ОК», приложение нажмёт кнопку автоматически.

**AutoFace не обходит биометрическую проверку:** лицо сначала должно быть распознано самой системой.

## Скачать

[GitHub Releases](https://github.com/Haradreamer/Honor-AutoFace/releases) — здесь будет размещён подписанный APK. Пока файл релиза не опубликован, не используйте сторонние «зеркала» или перепакованные APK.

## Функции

- Автоподтверждение после успешного распознавания лица.
- Задержка 0–100 мс, по умолчанию 10 мс.
- Светлая, тёмная и системная темы.
- Выбор языка при первом запуске и позднее в настройках: русский, английский, упрощённый китайский, испанский, португальский (Бразилия), арабский, турецкий, индонезийский, язык системы.
- Без root, ADB, учётной записи и интернета.

## Установка

1. Установите подписанный APK и запустите AutoFace.
2. Выберите язык, ознакомьтесь с запросом специальных возможностей (Accessibility).
3. Разрешите службу в настройках Accessibility.
4. Вернитесь в AutoFace и включите автоподтверждение.

### Заблокирован переключатель специальных возможностей

На некоторых прошивках MagicOS приложениям, установленным из APK, требуется отдельное разрешение ограниченных настроек.

1. Нажмите на недоступный переключатель AutoFace и закройте системное предупреждение.
2. Перейдите в **Настройки → Приложения → Управление приложениями → AutoFace**.
3. Вверху страницы приложения разрешите доступ к ограниченным настройкам (название может отличаться).
4. Вернитесь в специальные возможности и включите AutoFace.

Предоставляйте это разрешение только проверенным приложениям: Accessibility даёт доступ к содержимому доступных окон и нажатиям.

## Совместимость

**Проверено:** HONOR Magic9 Pro Max WKL-AN20, MagicOS 11. Остальные HONOR и HUAWEI ещё требуют проверки.

Приложение работает локально, без разрешения INTERNET и передачи данных. Face ID выполняется системой HONOR, а не AutoFace.
